========================================================================
                      ESTRUCTURA DE UN ARCHIVO ELF
========================================================================
Este archivo es un volcado (dump) real de un binario ELF de 64 bits. 
Contiene todas las estructuras fundamentales necesarias para entender 
cómo el Sistema Operativo (Linux) y las herramientas de desarrollo 
(enlazadores, depuradores) interpretan un programa ejecutable.

------------------------------------------------------------------------
1. ENCABEZADO ELF (ELF Header)
------------------------------------------------------------------------
Es el bloque inicial del archivo. Define la arquitectura, el tipo de 
archivo y, lo más importante, dónde se encuentran las dos tablas 
principales: Program Headers (para el OS) y Section Headers (para gcc/gdb).

  Mágico:   7f 45 4c 46 02 01 01 00 00 00 00 00 00 00 00 00 
  Clase:                             ELF64
  Datos:                             complemento a 2, little endian
  Version:                           1 (current)
  OS/ABI:                            UNIX - System V
  Versión ABI:                       0
  Tipo:                              DYN (Position-Independent Executable file)
  Máquina:                           Advanced Micro Devices X86-64
  Versión:                           0x1
  Dirección del punto de entrada:    0x8c0
  Inicio de encabezados de programa: 64 (bytes en el fichero)
  Inicio de encabezados de sección:  30395000 (bytes en el fichero)
  Opciones:                          0x0
  Size of this header:               64 (bytes)
  Size of program headers:           56 (bytes)
  Number of program headers:         9
  Size of section headers:           64 (bytes)
  Number of section headers:         36
  Section header string table index: 35

3. ASIGNACIÓN DE SECCIÓN A SEGMENTO
------------------------------------------------------------------------
Muestra cómo las "Secciones" lógicas encajan dentro de los "Segmentos" 
de memoria reales que el Kernel mapea. Por ejemplo, el segmento 02 
(que tiene permisos R E) contiene el código ejecutable (.text).

  Segmento Secciones...
   00     
   01     .interp 
   02     .interp .note.ABI-tag .note.gnu.build-id .gnu.hash .dynsym .dynstr .gnu.version .gnu.version_r .rela.dyn .rela.plt .init .plt .plt.got .text .fini .rodata .eh_frame_hdr .eh_frame 
   03     .init_array .fini_array .dynamic .got .data .bss 
   04     .dynamic

4. ENCABEZADOS DE SECCIÓN (Section Headers)
------------------------------------------------------------------------
Esta tabla es usada por herramientas como gcc, gdb o tu libckpt.so.

variables, .symtab para nombres de funciones, etc.)
